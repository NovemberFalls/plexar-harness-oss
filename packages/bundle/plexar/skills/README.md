# Plexar skills

In-house skills shipped with `@plexar/dsh-plexar`, mounted through the bundle's `skill-filesystem` `customSkillDirs` row.
Each is a `<name>/SKILL.md` bundle. The orch family is ported from Claude Code by `port` (body verbatim, harness tool map on top); `metadata.source_sha256` records the exact source version. Build new Plexar skills here directly.
